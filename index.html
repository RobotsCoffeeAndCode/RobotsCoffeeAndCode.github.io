It also illustrates how my development process aligns with professional standards for team collaboration, stakeholder communication, and security. My work includes three enhancements to my IT145, Foundations in Application Development, Project Two submission. I completed this Java project during my first term at Southern New Hampshire University. It is a console application designed for internal use by a rescue animal company to track its inventory. In this context, a rescue animal is an animal trained to perform rescue work, such as locating a person who has gone missing on a ski trail. The application features a simple menu system and a list-based inventory of rescue animals. It allows users to view all rescue animals, their training statuses, and whether a third party has reserved them for a rescue. Users can also add rescue animals to the inventory or update the reservation status of an animal that is in service. I will express more details about the application in the following section, but essentially it is a bare-bones, local data management application.

This artifact was selected because, although basic, it demonstrates the core functions required of effective software: robust user input and output with error handling, data structuring and storage, and algorithmic data manipulation. My three enhancements demonstrate my ability to build each core function. In addition, I changed the language that I wrote the original software in from Java to C++. I used clang-tidy throughout the development process to ensure security was never an afterthought. Lastly, I used CMake to statically link all libraries used within the application, ensuring that the binary runs on any Windows device after compilation.
